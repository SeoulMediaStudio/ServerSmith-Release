# Security Policy

## Supported versions

The most recent release of ServerSmith receives security updates. Please make
sure you are running the latest version before reporting an issue.

## Reporting a vulnerability

If you believe you have found a security vulnerability in ServerSmith, please
report it privately so we can address it before it is disclosed publicly.

- **Email:** info@seoulmediastudio.com
- Please include a description of the issue, the version affected, and steps to
  reproduce it.

We aim to acknowledge reports within a few business days and will keep you
informed as we investigate and resolve the issue. Please do not open a public
issue for security reports.

## Your data

ServerSmith stores your templates and settings locally on your PC, and your bot
token is kept in the Windows Credential Manager — never in plaintext and never
transmitted anywhere except to Discord when you build a server.
